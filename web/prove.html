Prove your agent's answer

Paste a provider's question about the food program and what your agent, or you, answered. Amazon Bedrock Automated Reasoning checks it against 7 CFR 226.20 held as formal logic and says whether the rules prove it, contradict it, or need one more fact. This is the same prove_answer Tally's agent calls, running as an AWS Lambda with no Tally around it.

Try it

Call it from your own code


    
No key, no Tally. The reply has verdict, the rules it rests on or breaks in the regulation's words, the premises the logic read, and missing_facts when one more fact would decide it. For a Strands agent, from tally.strands_hook import ProveAnswers and pass hooks=[ProveAnswers()]; every answer is proved with no prompt changes.
